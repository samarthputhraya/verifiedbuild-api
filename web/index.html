Internship matching on verified skills.

Anyone can ship a project with AI now, so a repo alone doesn't show skill. Proofolio reads a student's GitHub repo and asks them five questions about their own code, out loud or typed, in any language. Their answers become a skill report with evidence, and internships are matched on what they showed.

For recruiters: a ranked shortlist, with the evidence.

Applicants are ranked by a match score that uses verified skills, shared interests and verified hackathon results. Open any candidate to read each answer next to the exact code it was about. New applicants appear as they apply. Export the list as a CSV.

What's measured, and what isn't.

Every question names a real file and line range. Answers are scored against a rubric and the code itself, from 0 to 10. Language, accent and grammar don't count. The match score is a formula, not a model: 60% verified skills, 25% shared interests, 15% verified hackathons. Claimed skills count for nothing until they're shown.
